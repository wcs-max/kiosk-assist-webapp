# 말로 주문 — 키오스크 사용 보조 웹앱

PRD를 바탕으로 만든 프론트엔드 프로토타입입니다.

## 실행 방법
1. ZIP 압축을 풉니다.
2. 터미널에서 프로젝트 폴더로 이동합니다.
3. `python -m http.server 8000` 실행
4. 브라우저에서 `http://localhost:8000` 접속
5. `키오스크 화면 열기`를 누른 뒤, 새 탭에서 같은 주소의 `?mode=mobile&session=...` URL을 열어 휴대폰 화면을 테스트합니다.

## 구현된 기능
- 키오스크/모바일 화면 분리
- 세션 ID 기반 QR 연결 URL
- BroadcastChannel 및 localStorage 이벤트 기반 동일 브라우저 탭 간 동기화
- 한국어 Web Speech API 음성 인식(지원 브라우저 및 HTTPS/localhost 필요)
- 한국어 음성 안내(SpeechSynthesis)
- 메뉴 인식, 장바구니, 합계 계산, 결제 화면 이관 시뮬레이션
- 음성 인식 대체용 메뉴 선택 컨트롤

## 프로토타입 범위와 실제 서비스 전환 시 필요한 작업
- 현재 실시간 동기화는 **같은 브라우저/출처의 탭**을 대상으로 합니다. 서로 다른 기기 간 연결에는 PRD의 목표대로 WebSocket 서버와 세션 관리 백엔드가 추가로 필요합니다.
- QR 이미지는 QR Server 외부 이미지 서비스를 사용합니다.
- 결제는 카드리더기/POS 연동이 아닌 화면 전환 시뮬레이션입니다.
- 메뉴/가격은 데모 데이터이며 매장 POS 메뉴 API로 교체해야 합니다.
- 배포 시 HTTPS, 마이크 권한, 실제 기기별 음성 인식 호환성 테스트가 필요합니다.
